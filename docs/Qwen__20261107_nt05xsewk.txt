⚠️ УСТАРЕЛО (2026-11-07). Схема описывает polling-архитектуру и параметры Kafka,
которые противоречат текущему ТЗ (раздел 4 «Архитектура системы»):
  • @Scheduled polling → ТЗ требует gRPC-stream (не polling)
  • Retention raw-market-data 24h → ТЗ: 3 мин
  • Retention trading-signals 7d → ТЗ: 3 дня
  • Key trade-results: orderId → ТЗ: trade_id
  • События: ORDER_PLACED/POSITION_CLOSED/ORDER_FAILED → ТЗ: 8 значений (OPENED, PARTIAL_FILL, SL_HIT, TP_HIT, TIMEOUT_CLOSED, REJECTED, CANCELLED, CLOSED)
  • Только свечи → ТЗ: Candles + OrderBook + Trades + Info
Актуальная архитектура — в ТЗ раздел 4. Схема оставлена для истории.
