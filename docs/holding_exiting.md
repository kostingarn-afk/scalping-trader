## 0. Жёсткие правила

1. Никаких подставленных «типичных» значений. Каждый параметр — оценён с CI либо объявлен в политике как проектный выбор.
2. **Два ряда, два назначения.** Модель и её валидность — на сигнальном ряде. Стопы, P&L, издержки — на исполнимых условиях. Смешивать запрещено.
3. Все горизонтали выводятся при **наличии барьеров**. Формулы без барьеров — только диагностика, помечаются `REFERENCE_ONLY`.
4. Издержки закрытия платятся в обеих ветках решения → в правиле удержания участвует только их **разность**.
5. Выбор $\tau$ и любые изменения барьеров = запись в trial registry; отбор на train/CPCV.
6. Отсутствие допустимого $\tau$ — валидный исход: **нет сделки**.

## 1. Единицы и нотация

| Величина | Единица | Определение |
|---|---|---|
| $\Delta t$ | 1 мин | базовый бар |
| $\Delta_{MTF}$ | 10 мин | промежуточный фрейм: подтверждение режима, устойчивость $\hat\theta$ |
| $\Delta_{HTF}$ | 15 мин | бар режимного гейта |
| $\theta$ | мин$^{-1}$ | скорость возврата, шум-скорректированная |
| $\sigma$ | тики/$\sqrt{\text{мин}}$ | диффузионная волатильность |
| $\sigma_P$ | тики | стационарное СКО, $\sigma_P^2=\sigma^2/(2\theta)$ |
| $s$ | $\pm1$ | +1 лонг, −1 шорт |
| $\mu$ | тики | якорь, **заморожен на входе** |
| $A_t$ | безразмерн. | $A_t=-s\,(P_t-\mu)/\sigma_P$ |
| $D$ | тики | $D=A_0\sigma_P$ |
| $a,b$ | тики | расстояния TP и SL от цены входа |
| $C$ | тики | круговые издержки |

**КРИТИЧНО:** $\sigma\ne\sigma_P$. Квадратическая вариация $[P]_\tau=\sigma^2\tau$ (линейна). Терминальная дисперсия $\mathrm{Var}(\Delta P)=2\sigma_P^2(1-e^{-2\theta\tau})$ (насыщается). Подстановка одной вместо другой — запрещена.

$A_t>0$ — остаточный edge есть; $A_t\le0$ — edge исчерпан или против позиции.

## 2. Проектные входы политики (объявляются и замораживаются)

| Параметр | Смысл |
|---|---|
| $a,b$ | барьеры TP/SL, тики; требуется $a\le D$ для чистого MR |
| сетка $\tau$ | кратные $\Delta t$, диапазон объявлен |
| $q$ | допустимая вероятность смены режима до выхода |
| $\alpha_{total}$ | уровень для онлайн-теста валидности |
| $\lambda$ **или** $r_{alt}$ | риск-барьер удержания **или** альтернативная ставка дохода на время |
| $\rho_{max}$ | доля объёма бара для выхода |
| impact-бюджет | допустимый impact при немедленном выходе |
| buffer | запас до flat-at-close |

## 3.必要 условие и связывающий гейт

**Sanity-check (не гейт):** при $a\le D$
$$EV\le a-C\le D-C\ \Rightarrow\ EV>0\ \text{требует}\ D>C$$

**Связывающий гейт:** $EV_{LCB}(\tau)>0$ (§4).

`REFERENCE_ONLY`: $\tau_{min}=-\frac1\theta\ln(1-C/D)$ — горизонт без стопов. Не участвует в решении.

---

## 4. EV и дисперсия при барьерах

Исход сделки в тиках (до издержек):
$$X(\tau)=a\cdot\mathbf 1_{TP}-b\cdot\mathbf 1_{SL}+\Delta P_\tau\cdot\mathbf 1_{N}$$
$$EV(\tau)=\mathbb E[X(\tau)]-C,\qquad V(\tau)=\mathrm{Var}(X(\tau))$$

$p_{TP},p_{SL},p_N$ — вероятности **первого касания** OU с вертикальным барьером $\tau$. Замкнутой формы нет.

**Протокол оценки (выбрать один, объявить):**
- эмпирически по 1м с конвенцией «SL первым»;
- численно как краевая задача для оператора $\partial_t u=\theta(\mu-x)\partial_x u+\tfrac12\sigma^2\partial_{xx}u$ с $u=1$ на TP, $u=0$ на SL, $u(\cdot,0)=0$.

CI: блочный bootstrap (блок $\ge2\tau$) либо Newey–West при перекрытии. Конвенция «SL первым» смещает EV **вниз** — все ворота консервативны, объявить явно.

**Диагностическая верхняя оценка** $p_{SL}$ (валидна пока дрейф благоприятен):
$$p_{SL}(\tau)\le 2\Phi\!\left(-\frac{b}{\sigma\sqrt\tau}\right)$$
При больших $\tau$ оценка стремится к 1 и становится неинформативной. Использовать как верхнюю границу в EV, **не как гейт**.

## 5. Объектив выбора горизонта

Цикл = удержание + ожидание следующего сигнала $w$ (оценивается на замороженной политике; эндогенно порогу → помечать).

**Основной (риск-скорректированный темп):**
$$\max_{\tau\in\text{grid}}\ \frac{EV(\tau)}{\sqrt{V(\tau)\,(\tau+w)}}$$

**Альтернативный (объявить один):** $\max EV(\tau)/(\tau+w)$ при отдельном ограничении риска.

`REFERENCE_ONLY`, без стопов и без риска: $1-(1+x+\omega)e^{-x}=C/D$, $x=\theta\tau$, $\omega=\theta w$.

Отбор $\tau$ — на train/CPCV. Сетка регистрируется.

---

## 6. Верхние границы

$$\tau_{max}=\min(\tau_{edge},\ \tau_{regime},\ \tau_{mtf},\ \tau_{model},\ \tau_{liq},\ \tau_{session},\ \tau_{cap})$$

| Граница | Формула |
|---|---|
| $\tau_{edge}$ | $\max\{\tau: EV_{LCB}(\tau)>0\}$ |
| $\tau_{regime}$ | $\Delta_{HTF}\cdot\left\lfloor\dfrac{\ln\!\big((1-q)/\gamma_t(fav)\big)}{\ln \widehat P^{LCB}_{fav,fav}}\right\rfloor$ |
| $\tau_{mtf}$ | консервативная граница по 10м: при расхождении 10м и 15м состояний берётся меньшее из $\tau_{regime}$ и оценки выживания на 10м; расхождение трактуется как «режим под вопросом» |
| $\tau_{model}$ | горизонт инвариантности $\hat\theta$ (Research Spec §6.3) |
| $\tau_{liq}$ | $\Delta t\cdot\left\lceil\dfrac{Q}{\rho_{max}V_{1m}}\right\rceil$ — мягкая; немедленный выход допустим с impact по закону $\ Y\sigma_h\sqrt{Q/V_h}$ |
| $\tau_{session}$ | $T_{close}-t-\max(\tau_{liq},\Delta t)-\text{buffer}$ |
| $\tau_{cap}$ | объявленный предел скальпинга |

**Отдельный блокирующий гейт:** если $\gamma_t(fav)<1-q$, допустимых $n$ нет → **вход запрещён** независимо от сигнала.

Округление: $\tau_{min}$-подобные величины вверх, $\tau_{max}$ вниз; все $\tau$ кратны $\Delta t$; выход по close бара $\tau$.

**Условие входа:** существует $\tau$ в сетке с $EV_{LCB}(\tau)>0$ и $\tau\le\tau_{max}$. Иначе — нет сделки.

## 7. Правило удержания

Сравнение ветвей (издержки входа невозвратны, издержки закрытия сокращаются):
$$\text{Close now: } (P_t-P_0)-C^{now}_{close}$$
$$\text{Hold: } \mathbb E[P_{exit}]-P_0-\mathbb E[C^{later}_{close}]$$

$$\boxed{\text{Hold}\iff m_{rem}-\lambda\,s_{rem}>\mathbb E[C^{later}_{close}]-C^{now}_{close}}$$

$m_{rem},s_{rem}$ — условные ожидание и СКО **остаточного** движения при барьерах, считаются тем же протоколом §4 из текущего состояния.

**Альтернатива через альтернативную ставку (объявить один вариант):**
$$\text{Hold}\iff \frac{m_{rem}}{\tau_{rem}+w}\ge r_{alt}$$

`REFERENCE_ONLY`, без барьеров:
$$m_{rem}=A_t\sigma_P(1-e^{-\theta\tau_{rem}}),\quad s_{rem}=\sigma_P\sqrt{2(1-e^{-2\theta\tau_{rem}})}$$
$$\Rightarrow A_t>\lambda\sqrt{2\coth\!\left(\frac{\theta\tau_{rem}}{2}\right)}$$

Свойства диагностической формы: $\tau_{rem}\to\infty$ → порог $\lambda\sqrt2$; $\tau_{rem}\to0$ → порог $\to\infty$. **Отменено:** правило $|Z_{hold}|\approx\tfrac12|Z_{entry}|$ — выводилось из двойного учёта издержек закрытия.

**Продление в MR-режиме:** при $A_t\le0$ остаточный edge против позиции → выход. Трейлинг допустим только при подтверждённом momentum-режиме; на текущем датасете он не идентифицируем → недоступен.

## 8. Онлайн-тест валидности модели

На **сигнальном** ряде, в $A$-координате, якорь заморожен:
$$A_t\mid A_0\sim\mathcal N\!\left(A_0e^{-\theta t},\ 1-e^{-2\theta t}\right)$$

Неблагоприятное направление — **ниже** нижней полосы (единообразно для лонга и шорта).

Консервативная полоса:
$$A_0^{LCB}e^{-\theta_{LCB}t}\ -\ z_{1-\alpha_{check}}\sqrt{1-e^{-2\theta_{UCB}t}}$$

$\alpha_{check}=\alpha_{total}/n_{checks}$, $n_{checks}=\tau_{max}/\Delta t$ (Bonferroni, консервативно из-за корреляции проверок).

$\sigma_P$ входит в $A_0$ → его CI пропагируется в $A_0^{LCB}$.

Отвержение → выход по политике. Это тест **валидности модели**, не стоп-лосс.

## 9. Таблица выходов

| Триггер | Условие | Тип |
|---|---|---|
| Anchor / edge | $A_t\le$ порог §7 | штатный |
| Overshoot | $A_t\le0$ | штатный |
| TP / SL | касание барьера (конвенция §2) | жёсткий |
| Time stop | $t\ge\tau$ выбранного | жёсткий |
| Model invalid | ниже полосы §8 | жёсткий |
| Regime breaker | 1м CUSUM-of-squares / знак кумулятивного отклонения | жёсткий |
| Regime confidence | $\gamma_t(fav)<1-q$ | жёсткий |
| Regime confirmation (10м) | расхождение 10м и 15м состояний | редукция $\tau_{max}$ / no-trade |
| Vol spike | выброс range-based $\sigma$ → пересчёт $\tau_{max}$ | редукция/выход |
| Close-cost drift | $\mathbb E[C^{later}_{close}]-C^{now}_{close}$ растёт | по §7 |
| Session | $\tau_{session}$ | жёсткий |

Рост спреда влияет **через разность** ожидаемых издержек закрытия, не через условие входа.

## 10. Исходы и скоуп

- Нет допустимого $\tau$ → отчёт «нет сделки», без ослабления порогов.
- Оптимальный $\tau>\tau_{cap}$ → `SCOPE_VIOLATION`, требуется re-specification, не продление.
- $\gamma_t(fav)<1-q$ → вход запрещён.
- $D\le C$ при $a\le D$ → вход запрещён (арифметика).

## 12. Запрещено

Подставлять $\sigma_P$ вместо $\sigma$ в bound касания. Гейтовать по $p_{SL}$. Использовать безбарьерные формулы как операционные. Вычитать уровень $C_{close}$ в правиле удержания. Смешивать сигнальный и исполнимый ряды. Использовать среднее время пребывания режима вместо квантиля. Игнорировать $\gamma_t$. Подбирать $\lambda$/$r_{alt}$/$q$ post hoc. Округлять $\tau$ в оптимистичную сторону. Разрешать порядок TP/SL внутри бара оптимистично. Тюнить сетку без registry. Продолжать при отсутствии допустимого $\tau$.

## 15. Арифметический пример (не эмпирический факт)
