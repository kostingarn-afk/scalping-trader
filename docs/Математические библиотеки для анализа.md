# 🧮 Математические библиотеки для анализа сигналов в скальпинге

Для скальпинга математический анализ сводится к нескольким ключевым задачам: **выявление краткосрочных аномалий цены**, **оценка вероятности движения**, **фильтрация шума** и **оптимизация точек входа/выхода**. Разберем библиотеки по категориям математических задач.

## 2. 📈 Статистический анализ

### **`scipy.stats`** — распределения и тесты

```python
from scipy import stats
import numpy as np

# 1. Проверка нормальности распределения доходностей
returns = np.diff(close) / close[:-1]
stat, p_value = stats.shapiro(returns)  # тест Шапиро-Уилка
# Если p < 0.05 → распределение НЕ нормальное (хвосты тяжелее)

# 2. Расчет "толстых хвостов" (kurtosis) — важно для риска
kurtosis = stats.kurtosis(returns)
# kurtosis > 3 → экстремальные движения вероятнее, чем в нормальном распределении

# 3. Z-score для поиска аномалий цены
z_scores = np.abs(stats.zscore(close))
anomalies = np.where(z_scores > 3)[0]  # цены, отклоняющиеся на 3σ

# 4. Корреляция между инструментами (для парного скальпинга)
corr, p_value = stats.pearsonr(price_a, price_b)

# 5. T-test — сравнение двух периодов (до/после новости)
t_stat, p_value = stats.ttest_ind(returns_before, returns_after)
```

import numpy as np

# Быстрые расчеты на массивах (векторизация!)
mean_price = np.mean(close[-20:])
std_price = np.std(close[-20:])

# Скользящее среднее через stride_tricks (быстрее rolling)
def rolling_mean(arr, window):
    shape = arr.shape[:-1] + (arr.shape[-1] - window + 1, window)
    strides = arr.strides + (arr.strides[-1],)
    return np.mean(np.lib.stride_tricks.as_strided(arr, shape=shape, strides=strides), axis=-1)

# Экспоненциальное среднее (EMA) через cumprod
def ema(prices, period):
    alpha = 2 / (period + 1)
    weights = (1 - alpha) ** np.arange(len(prices))[::-1]
    return np.convolve(prices, weights / weights.sum(), mode='valid')

# Волатильность (annualized)

## 4. 🔬 Обработка сигналов и фильтрация шума

### **`scipy.signal`** — фильтры для очистки данных

```python
from scipy.signal import savgol_filter, butter, filtfilt, find_peaks

# 1. Фильтр Савицкого-Голея — сглаживание без потери формы
# Идеально для скальпинга: убирает шум, сохраняет пики
smoothed = savgol_filter(close, window_length=11, polyorder=3)

# 2. Butterworth фильтр — низкочастотный (убирает шум)
def lowpass_filter(data, cutoff=0.1, fs=1.0, order=4):
    nyq = 0.5 * fs
    normal_cutoff = cutoff / nyq
    b, a = butter(order, normal_cutoff, btype='low', analog=False)
    return filtfilt(b, a, data)

filtered = lowpass_filter(close, cutoff=0.1)

# 3. Детектор пиков — для поиска локальных экстремумов
peaks, properties = find_peaks(close, height=150, distance=5, prominence=2)
valleys, _ = find_peaks(-close, distance=5, prominence=2)

# 4. Производные (скорость изменения цены)
velocity = np.gradient(close)      # 1-я производная
acceleration = np.gradient(velocity)  # 2-я производная
# Если velocity > 0 и acceleration > 0 → сильный восходящий импульс
```

## 7. 📚 Анализ микроструктуры рынка (стакан)

### Самописные решения на `numpy`

```python
import numpy as np
from collections import deque

class OrderBookAnalyzer:
    def __init__(self, depth=10):
        self.depth = depth
        self.bids = deque(maxlen=100)  # [(price, volume), ...]
        self.asks = deque(maxlen=100)
    
    def update(self, bids, asks):
        self.bids = bids[:self.depth]
        self.asks = asks[:self.depth]
    
    def imbalance(self):
        """Дисбаланс стакана — ключевой сигнал для скальпинга"""
        bid_volume = sum(v for _, v in self.bids)
        ask_volume = sum(v for _, v in self.asks)
        total = bid_volume + ask_volume
        if total == 0:
            return 0
        return (bid_volume - ask_volume) / total  # от -1 до 1
        # > 0.3 → давление покупателей
        # < -0.3 → давление продавцов
    
    def weighted_mid_price(self):
        """Взвешенная средняя цена (лучше чем mid-price)"""
        best_bid = self.bids[0][0]
        best_ask = self.asks[0][0]
        bid_vol = self.bids[0][1]
        ask_vol = self.asks[0][1]
        return (best_bid * ask_vol + best_ask * bid_vol) / (bid_vol + ask_vol)
    
    def spread(self):
        """Спред — индикатор ликвидности"""
        return self.asks[0][0] - self.bids[0][0]
    
    def depth_ratio(self, levels=5):
        """Соотношение глубины на разных уровнях"""
        bid_depth = sum(v for _, v in self.bids[:levels])
        ask_depth = sum(v for _, v in self.asks[:levels])
        return bid_depth / ask_depth if ask_depth > 0 else 0
    
    def large_orders_ratio(self, threshold_multiplier=3):
        """Доля крупных заявок (возможные маркетмейкеры)"""
        avg_bid = np.mean([v for _, v in self.bids])
        avg_ask = np.mean([v for _, v in self.asks])
        
        large_bids = sum(1 for _, v in self.bids if v > avg_bid * threshold_multiplier)
        large_asks = sum(1 for _, v in self.asks if v > avg_ask * threshold_multiplier)
        
        return large_bids / (large_bids + large_asks) if (large_bids + large_asks) > 0 else 0.5
```

## 9. 🎯 Готовые математические стратегии для скальпинга

### **Стратегия 1: Mean Reversion на Bollinger + Z-score**

```python
import numpy as np
from scipy import stats

def mean_reversion_signal(close, window=20, entry_z=2.0, exit_z=0.5):
    """Возврат к среднему — классика скальпинга"""
    mean = np.mean(close[-window:])
    std = np.std(close[-window:])
    
    # Z-score текущей цены
    z_score = (close[-1] - mean) / std if std > 0 else 0
    
    signal = None
    if z_score < -entry_z:
        signal = 'BUY'   # цена сильно ниже среднего → отскок вверх
    elif z_score > entry_z:
        signal = 'SELL'  # цена сильно выше среднего → откат вниз
    elif abs(z_score) < exit_z:
        signal = 'CLOSE' # цена вернулась к среднему → фиксация
    
    return signal, z_score
```

### **Стратегия 2: Momentum + Volume Breakout**

```python
def momentum_breakout(close, volume, window=10, vol_threshold=2.0):
    """Пробой на объеме"""
    # Импульс (ROC)
    roc = (close[-1] - close[-window]) / close[-window]
    
    # Средний объем
    avg_volume = np.mean(volume[-window:])
    current_volume = volume[-1]
    
    # Объемный всплеск
    volume_spike = current_volume / avg_volume if avg_volume > 0 else 0
    
    # Максимум за период
    max_price = np.max(close[-window:])
    
    signal = None
    if roc > 0.005 and volume_spike > vol_threshold and close[-1] >= max_price * 0.998:
        signal = 'BUY'  # пробой сопротивления на объеме
    
    return signal, roc, volume_spike
```

### **Стратегия 3: Order Flow Imbalance**

```python
def order_flow_imbalance(bids, asks, trades, threshold=0.3):
    """Анализ потока ордеров"""
    # Дисбаланс стакана
    bid_vol = sum(v for _, v in bids[:5])
    ask_vol = sum(v for _, v in asks[:5])
    book_imbalance = (bid_vol - ask_vol) / (bid_vol + ask_vol)
    
    # Агрессивные покупки/продажи (по последним сделкам)
    buy_volume = sum(v for p, v in trades if p >= asks[0][0])
    sell_volume = sum(v for p, v in trades if p <= bids[0][0])
    flow_imbalance = (buy_volume - sell_volume) / (buy_volume + sell_volume)
    
    # Комбинированный сигнал
    combined = 0.6 * book_imbalance + 0.4 * flow_imbalance
    
    signal = None
    if combined > threshold:
        signal = 'BUY'
    elif combined < -threshold:
        signal = 'SELL'
    
    return signal, combined
```

### **Стратегия 4: Volatility Breakout (TTM Squeeze)**

```python
def ttm_squeeze(high, low, close, bb_period=20, kc_period=20, kc_mult=1.5):
    """Сжатие волатильности → пробой"""
    # Bollinger Bands
    bb_std = np.std(close[-bb_period:])
    bb_width = 2 * 2 * bb_std  # ширина BB
    
    # Keltner Channel (через ATR)
    atr = talib.ATR(high, low, close, kc_period)[-1]
    kc_width = 2 * kc_mult * atr
    
    # Squeeze: BB внутри KC
    squeeze_on = bb_width < kc_width
    
    # Momentum (линейная регрессия)
    x = np.arange(20)
    slope, _, _, _, _ = stats.linregress(x, close[-20:])
    momentum = slope
    
    signal = None
    if squeeze_on:
        signal = 'WAIT'  # ждем пробоя
    else:
        if momentum > 0:
            signal = 'BUY'
        elif momentum < 0:
            signal = 'SELL'
    
    return signal, squeeze_on, momentum
```

### **Для базовой версии (MVP):**
1. **`ta-lib`** — индикаторы (RSI, MACD, BB, ATR)
2. **`numpy`** — быстрые статистики, Z-score
3. **`scipy.stats`** — проверка распределений
4. **`scipy.signal`** — сглаживание (savgol_filter)

### **Для продвинутой версии:**
5. **`statsmodels`** — стационарность, коинтеграция
6. **`lightgbm`** — ML-классификация сигналов
7. **`optuna`** — оптимизация параметров
8. **`vectorbt`** — быстрый бэктестинг

### **Критичные математические концепции для скальпинга:**

| Концепция | Библиотека | Зачем |
|-----------|------------|-------|
| Z-score | `numpy`, `scipy` | Поиск аномалий цены |
| ATR | `ta-lib` | Динамический stop-loss |
| Order Imbalance | самописный код | Анализ стакана |
| Калмановский фильтр | `pykalman` | Сглаживание цены |
| GARCH | `arch` | Прогноз волатильности |
| Коинтеграция | `statsmodels` | Парный скальпинг |
| Gradient Boosting | `lightgbm` | Классификация сигналов |

## 💡 Практический совет

Для скальпинга **не гонитесь за сложной математикой**. Самые прибыльные стратегии часто используют:
- **Z-score + Bollinger** (mean reversion)
- **Volume + Momentum** (breakout)
- **Order Book Imbalance** (микроструктура)

Сложные ML-модели (LSTM, Transformer) обычно **проигрывают** простым стратегиям в скальпинге из-за:
1. Высокого уровня шума в тиковых данных
2. Нестационарности рынка
3. Задержек inference

Начните с `ta-lib` + `numpy` + `scipy`, и только потом добавляйте ML, если базовые стратегии не дают результата.
