## 0. Жёсткие правила

1. Никаких подставленных «типичных» параметров. Число либо оценено с CI, либо помечено `UNVERIFIED_HYPOTHESIS`.
2. **Шум-коррекция применяется только к идентификации параметров модели. Edge никогда не корректируется вверх.** Спред — издержка, а не ошибка измерения.
3. Один ценовой ряд ↔ один набор издержек. Смешивать запрещено (§6.1).
4. Gate 0b блокирующий. При провале — отчёт и остановка, не подбор моделей.
5. Политика заморожена (§4). Любое изменение конфигурации = запись в trial registry.
6. Все инференсы — по таблице §10.1, не единым правилом.
7. Модели, требующие отсутствующих данных, не реализуются (§9.3).

## 2. Gate D — целостность данных

- доля и распределение пропущенных баров;
- доля нулевых объёмов (исключать, не заполнять);
- аукционные принты помечены и исключены из оценки;
- границы сессий, TZ, DST зафиксированы;
- конвенция таймстемпа: решения в $t$ используют только бары с $\text{close\_time}\le t$;
- корректировки корпоративных действий без look-ahead;
- распределение $|\Delta P|$ в тиках: если мода 0–1 тик, сигнал может быть неразрешим;
- **запрет overnight:** статистика не содержит доходностей через границу сессии.

Провал критичного пункта → стоп.

## 3. Требуется от пользователя до старта

Инструмент/биржа, tick size; тариф за сторону и минимальная комиссия; часы сессии и TZ; есть ли bid/ask в файлах; доступность тиков/L2; целевой $\tau_{hold}$ и лимит просадки; капитал; тип ордера.

Без первых трёх пунктов Gate 0 не вычислим — работа ограничивается §2, §6, §7.

## 4. Замороженная политика (заполняется до подгонки)

Двухфазная заморозка.

**Фаза A — до оценки параметров, фиксируется и не меняется:**
- ценовой ряд сигнала (§6.1);
- геометрия барьеров: $TP$, $SL$ в тиках, вертикальный барьер $h$;
- $|Z_{entry}|$ (стартовое значение объявляется, не оптимизируется);
- сайзинг: правило и лимит инвентаря; максимум одна позиция;
- flat-at-close; запрет входов в последние $N$ минут сессии;
- условия no-trade (§9.2);
- $\kappa$-запас — только отчётный, не решающий.

**Фаза B — вычисляется один раз из $\hat\theta$:** $\tau^*$, $t_{1/2}$. Далее не тюнится.

Любое отклонение = новая запись в registry с инкрементом $N_{trials}$.

WR не свободен: он определяется геометрией барьеров. Тюнинг барьеров ради WR без пересчёта $\mathbb{E}[W],\mathbb{E}[L]$ запрещён.

## 5. Метка

Один вариант, фиксируется до отбора моделей: fixed-horizon $y_t=P_{t+h}-P_t$ (тики) либо triple-barrier. Из метки: $h_{max}=\max_k h_k$ для purging.

## 6. Ценовые ряды, шум, идентификация

### 6.1 Правило согласования (единственный допустимый вариант на этом датасете)

Сигнал и доходности считаются на **mid/VWAP-ряду**; вычитается **полный круговой Cost** (спред + fees + slippage). Спред оценён, не измерен → `UNVERIFIED`, обязателен стресс-тест ×1.5.

Exec-to-exec вариант ($bid_{t+\tau}-ask_t$, только fees) разблокируется лишь при появлении L1. Смешивать варианты запрещено.

### 6.2 Range-based оценки дисперсии (главный ресурс OHLC)

$$\sigma^2_{P}=\frac{\ln^2(H/L)}{4\ln 2},\qquad
\sigma^2_{GK}=\tfrac12\ln^2\!\frac{H}{L}-(2\ln 2-1)\ln^2\!\frac{C}{O}$$
$$\sigma^2_{RS}=\ln\frac{H}{C}\ln\frac{H}{O}+\ln\frac{L}{C}\ln\frac{L}{O}$$

Диагностика bounce/шума: отношение close-to-close дисперсии к range-based. Существенное превышение → шум доминирует. Все оценки предполагают непрерывную диффузию; при прыжках смещены — помечать.

### 6.3 Идентификация $\theta$ через инвариантность по $\Delta t$ (заменяет эвристику)

При $P^*=P+\eta$, $\mathrm{Var}(\eta)=\omega^2$, $\sigma_P^2=\sigma^2/(2\theta)$:
$$\rho_{obs}=\frac{\rho}{1+\omega^2/\sigma_P^2},\qquad
\hat\theta_{obs}(\Delta)=\theta+\frac{\ln\!\left(1+\omega^2/\sigma_P^2\right)}{\Delta}$$

Процедура: оценить $\hat\theta$ на $\Delta\in\{1,2,3,5,10,15\}$ мин; регрессия $\hat\theta(\Delta)$ на $1/\Delta$; **intercept = шум-скорректированная $\theta$**, slope = логарифм отношения шума.

- Если дрейф $\hat\theta$ по $\Delta$ отсутствует → шум незначим, брать любую $\Delta$ на плато signature plot.
- Если дрейф есть → использовать intercept, CI обязателен.
- Если CI intercept содержит 0 → **модель неидентифицируема**, OU не используется.

Marriott–Pope $\hat\rho_c=\hat\rho+(1+3\hat\rho)/n$ — второстепенная поправка $O(1/n)$; применять после шум-коррекции, не вместо.

### 6.4 Attenuation сигнала (errors-in-variables)

Регрессия на шумном регрессоре занижает наклон в $\dfrac{\sigma_P^2}{\sigma_P^2+\omega^2}$ раз. Это объясняет разрыв между $\rho_{model}$ и измеренным $\hat\varphi$. **Разрыв документировать, edge вверх не корректировать.**

### 6.5 Модельный ориентир (не порог, не факт)

$$\rho_{model}=-\sqrt{\frac{1-e^{-\theta\tau}}{2}},\qquad \lim_{\tau\to\infty}|\rho_{model}|=\frac{1}{\sqrt2}$$

Используется только как верхняя граница и диагностика разрыва. Запрещено подставлять в Gate 0.

### 6.6 Variance ratio

$$VR(\tau)=\frac{\mathrm{Var}(r_{t\to t+\tau})}{\tau\,\mathrm{Var}(r_{t\to t+1})},\qquad \sigma_\tau=\sigma_1\sqrt{\tau\,VR(\tau)}$$

Для mean reversion $VR<1$. $\sigma\sqrt\tau$ без $VR$ запрещён.

### 6.7 Десезонализация

$$\tilde r_t=\frac{r_t}{\hat s(\text{minute\_of\_session}(t))}$$

$\hat s$ оценивается на train. Все пороги задаются на $\tilde r$.

## 7. Gate 0 — двухстадийный, без выдуманных констант

### 7.1 Стадия 0a — справочная, до подгонки

$$\varphi^*=\frac{\text{Cost}}{\sigma_\tau},\qquad \sigma_\tau=\sigma_1\sqrt{\tau\,VR(\tau)}$$

$\varphi^*$ — **требуемая** доля извлечения движения для безубыточности. Никаких предположений о достижимом $\rho$ не делается. Отчитаться таблицей $\varphi^*(\tau)$ для $\tau\in\{1,3,5,10,15,30\}$.

Если $\varphi^*>1$ при всех $\tau$ — движение меньше издержек, скальпинг невозможен арифметически; стоп.

### 7.2 Стадия 0b — блокирующая, после подгонки одного конфига

$$\hat\varphi=\frac{\left|\widehat{\mathbb{E}}[R_{net}\mid \text{signal}]\right|}{\sigma_\tau}$$

Оценка OOS, инференс по §10.1. **Ворота: нижняя граница CI для $\hat\varphi$ превышает $\varphi^*$.**

Отчётный запас: $\text{margin}=\hat\varphi_{LCB}/\varphi^*$. $\kappa$ не участвует в решении.

### 7.3 Протокол kill

Перед объявлением отказа обязательно приложить: результат §6.3 (идентифицируема ли $\theta$), §6.2 (доминирует ли шум), §6.4 (величина attenuation), разрыв с §6.5. Отказ формулируется как «при данных условиях и издержках edge не подтверждён», не как «альфы не существует».

## 8. Модуль OU — единственный генератор сигнала

- Оценка $\theta,\mu,\sigma$: $\Delta t_{est}$ по §6.3, окно 4–8 недель, ряд по §6.1.
- Сигнал: $Z_t$ пересчёт каждый 1м на $\tilde r$.
- Дискретная форма: $P_{t+\Delta}=\mu(1-\rho)+\rho P_t+\varepsilon_t$, $\rho=e^{-\theta\Delta}$, $\mathrm{Var}(\varepsilon)=\frac{\sigma^2}{2\theta}(1-e^{-2\theta\Delta})$.
- Выход: $t_{1/2}=\ln2/\hat\theta$, $\tau^*=\frac{1}{2\theta}\ln\!\left(1+\frac{2\theta(\mu-P_t)^2}{\sigma^2}\right)$, оба с блочным bootstrap CI.
- Если CI для $t_{1/2}$ шире двукратного — сигнал не используется.
- Вход и выход на 1м. Старшие фреймы гейтируют, но не закрывают позицию.

## 9. Гейты и фильтры

### 9.1 Режим: 15м HMM + 1м model-free breaker

**HMM:** оценка на 15м, $K=2$ по умолчанию. Эффективная выборка — переходы:
$$N_{trans}=\#\{t:\arg\max_k\gamma_t(k)\neq\arg\max_k\gamma_{t+1}(k)\},\qquad N_{trans}\ge 10K(K-1)$$

При провале: $K\downarrow$, приор на $P$, либо модуль только исследовательский. На 1 году данных при длительных режимах провал вероятен — ожидать его.

**Фильтрация только на 15м.** Причина: агрегация HMM не является HMM; $\exp(Q\Delta)$ навязывает экспоненциальные времена пребывания и требует embeddability. 1м-фильтрация HMM допускается лишь как помеченная аппроксимация, обязанная превзойти baseline без неё на CPCV.

**1м circuit breaker (model-free, закрывает задержку до 15 мин):**
- CUSUM-of-squares на $\tilde r$: $S_t^{(2)}=\sum(\hat\varepsilon_i^2/\hat\sigma^2-1)$;
- контроль знака кумулятивного отклонения от VWAP сессии.

Срабатывание любого → блокировка новых входов до сброса. Латентные состояния не используются.

### 9.2 Фильтр волатильности/прыжков (заменяет jump-diffusion в критическом пути)

Отношение range-based дисперсии к close-to-close (§6.2) как прокси прыжковой активности. Блокировать входы при выбросах. Jump-diffusion как SDE — исследовательская ветка, слабо идентифицируема на 1м.

### 9.3 Отложено до получения данных

| Модуль | Требуется | Причина |
|---|---|---|
| Hawkes | тики | $\Delta t\le1/(3\beta)$; на 1м алиасинг |
| Avellaneda-Stoikov | L1/L2 | нет bid/ask |
| OBI | L2 | нет стакана |
| Almgren-Chriss | impact | при $\kappa T\gg1$ решение ≈ market order |
| VPIN (BVC) | тики для валидации | прокси прокси; только research, вне критического пути |

### 9.4 Сайзинг и вместимость

$$\text{Impact}\approx Y\,\sigma_h\sqrt{Q/V_h},\qquad Y\in[0.5,1]$$

Ограничить $Q$: Impact ≤ 0.25 от ожидаемого edge. participation cap объявляется в политике.

## 10. Инференс

### 10.1 Таблица «оценка → метод» (заменяет blanket $N_{eff}$)

| Оценка | Перекрытие | Инференс |
|---|---|---|
| $\theta,\mu,\sigma$ по неперекрывающимся $\Delta$ | нет | $n$ наблюдений; блочный bootstrap для устойчивости |
| $\hat\varphi$, $\hat\rho$ по сигналам с горизонтом $\tau$ | да | Newey–West, $L=\lceil\tau/\Delta t\rceil$ |
| Метрики стратегии по сделкам | да | NW + блочный bootstrap, блок $\ge2\tau_{hold}$ |
| $VR(\tau)$ | да | NW / блочный bootstrap |

i.i.d. bootstrap запрещён везде, где есть перекрытие.

### 10.2 CPCV

Purging по $h_{max}$; embargo $\delta\approx3\times$ горизонт ACF; block-based $\binom{\phi}{k}$ комбинаций. Полный $\binom{N}{k}$ не вычислим.

### 10.3 DSR — уровень и формулы

**Уровень: одна сделка.** $R_i$ — net-результат в тиках; $SR=\overline{R}/s_R$; skew $\gamma_3$ и **неизбыточная** kurtosis $\gamma_4$ считаются по $R_i$; $T$ = число независимых сделок. **Аннуализация внутри DSR запрещена.**

$$\widehat{SE}(\widehat{SR})=\sqrt{\frac{1-\gamma_3\widehat{SR}+\frac{\gamma_4-1}{4}\widehat{SR}^2}{T-1}}$$

Контроль: $\gamma_3=0,\gamma_4=3\Rightarrow1+\widehat{SR}^2/2$. Формула с $SR^4$ из v2 отменена как ошибочная.

$$SR^*\approx\sqrt{\mathbb{V}[\widehat{SR}_{trials}]}\left[(1-\gamma)\Phi^{-1}\!\left(1-\tfrac1N\right)+\gamma\Phi^{-1}\!\left(1-\tfrac1{Ne}\right)\right],\ \gamma\approx0.5772$$

$$DSR=\Phi\!\left(\frac{\widehat{SR}-SR^*}{\widehat{SE}(\widehat{SR})}\right)$$

$N=N_{eff}^{trials}$ при доступной корреляционной матрице испытаний: $N_{eff}^{trials}=(\sum\lambda_i)^2/\sum\lambda_i^2$. Иначе сырое $N_{trials}$ с пометкой `CONSERVATIVE`.

### 10.4 Trial registry

Глобальный лог всех конфигураций за весь цикл: модель, фрейм, окно, барьеры, сайзинг, фильтры. Без registry DSR не вычисляется.

### 10.5 Множественное тестирование

FDR Бенджамини–Хохберга — только для метрик с p-value. Для Wasserstein/Brier — bootstrap-пороги.

## 11. Реализм исполнения

- Сигнальная цена ≠ цена филла; на этом датасете — правило §6.1 с полным Cost.
- Только завершённые HTF-бары.
- Flat-at-close; без overnight в статистике.
- Стресс: Cost ×1.5, spread-оценка ×2.

---

## 12. Мониторинг

CUSUM-of-squares; Chow по известным событиям; дрейф $\hat\theta$ через непересечение CI **по таблице §10.1**; Brier для вероятностных выходов.

Re-estimation (параметры) отдельно от re-specification (структура). Cooldown $\ge2t_{1/2}^{alpha}$. Rollback при $DSR_{new}<DSR_{old}-\Delta_{rollback}$. Alpha decay: экспоненциальная и степенная, выбор AIC/BIC; на 1 году данных оценка `LOW_CONFIDENCE`, не используется для автопланирования. Триггеры не применяются к аукционным окнам.
