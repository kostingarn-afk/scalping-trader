Наблюдения:

1. **Вердикт — `NO_ENTRY` (0/4).** Ни один инструмент не проходит входной гейт: `EV_LCB(τ*) < 0`.
2. **`τ*` лежит на `τ_cap = 60` у всех четырёх** → `SCOPE_VIOLATION`. Объектив
   `EV/√(V(τ)(τ+w))` убывает медленнее, чем растёт `V`, поэтому «лучший» горизонт упирается
   в предел. Расширять сетку внутри R3 запрещено — это ре-спецификация горизонта.
3. **Геометрия барьеров не покрывает издержки.** Флаг `NEGATIVE_BOUND` у MTSS (TP 3 ≤ Cost 3.52)
   и T (10 ≤ 13.56): по §3 `EV ≤ a − Cost`, то есть положительный EV недостижим при любых
   вероятностях. У PLZL и VTBR граница положительна, но EV всё равно отрицателен
   (p_SL ≈ 1.6·p_TP: реверсия на таких барьерах не успевает проявиться).
   Это вывод о замороженной политике (`k_tp = 2σ₁`, `k_sl = 1.5σ₁`), а не о коде; менять `k`
   внутри изменения нельзя — выносится как решение владельца.
4. **Сверка с краевой задачей**: на синтетике OU (`θ = 0.2`, `σ = 0.5` тика/√мин, барьеры ±1,
   `τ = 10`) эмпирика по барам даёт `p_TP = 0.4315` против `0.4319` из PDE при шаге 1 с.
   При шаге 10 с эмпирика даёт `0.3975`: бар видит только свой high/low, и на грубом разрешении
   касания недосчитываются — направление смещения консервативное (в EV ворота вниз).
5. **CI**: 22–53 кластера на инструмент, ширина интервала 0.15–4.30 тика (растёт с τ и с
   волатильностью инструмента). При одном окне или окне короче `2τ` точка помечается
   `CI_DEGENERATE` и вход не разрешает.
6. **`p_SL > p_TP` на всех τ у всех четырёх** (например MTSS: 0.35 против 0.18 при τ = 1):
   на минутном горизонте вход против отклонения от VWAP не даёт перевеса, сопоставимого
   с барьерами `2σ₁/1.5σ₁`. Это то же, что показывает sanity-граница.

## Принятые решения

- **Протокол первого касания — эмпирический по 1m, «SL первым».** Численная краевая задача
  точнее по модели, но требует доверия к OU там, где Gate 1 показал `t½ ≈ 2τ_cap`;
  эмпирика с консервативной конвенцией ближе к данным. Численный вариант — `REFERENCE_ONLY`,
  реализуется только как сверка на синтетике.
- **CI — кластерный bootstrap по торговым окнам.** Соседние исходы зависимы внутри окна;
  блочный bootstrap по подряд идущим сигналам вырождается (сигналы разрежены и блок `2τ` подряд
  не набирается), поэтому блок — само окно. Требование «блок ≥ 2τ» проверяется статусом
  `CI_DEGENERATE`.
- **`τ*` ищется на train, `EV_LCB` — входной гейт.** Отбор по верхней оценке EV запрещён.
  Множество поиска — `τ ≤ τ_cap`; оптимум за пределом даёт `SCOPE_VIOLATION`, а не «лучший
  из допустимых».
- **Горизонт входа — `τ*`, а не «первый τ с положительным `EV_LCB`».** Иначе горизонт выбирался
  бы по данным внутри дня.
- **TP привязан к издержкам: `a = max(2·σ₁, ceil(k_cost·Cost))`, `k_cost = 3`.**
  `PROJECT-DECISION:barrier-cost-floor`. До этого барьер `2σ₁` у MTSS и T был меньше круговых
  издержек, и по §3 `EV ≤ a − Cost` положительный EV был недостижим в принципе. `k_cost`
  объявлен в политике, а не подобран по результату; изменение политики фиксируется новой
  записью registry (`policy` в артефакте содержит `k_cost` и `floor_applied`).
- **Окно оценки `θ` фиксировано из R2 (8 недель), но для EV используется train-разбиение R4.**
  В R3 границы train/OOS объявляются заранее и пишутся в артефакт, чтобы R4 не пере-выбирал их
  по результату.
- **`τ_max` считается по семи компонентам, отсутствие компонента не заменяется единицей.**
  Если компонент не идентифицирован (например, Gate 2 провален), он помечается `REFERENCE_ONLY`
  и `τ_max` берётся по остальным — с явным флагом, а не молча.
- **Правило удержания — λ-форма.** `|Z_hold| ≈ ½|Z_entry|` отменено (§7 `holding_exiting.md`).
- **Бонферрони для онлайн-полосы.** `α_check = α_total/n_checks`, `n_checks = τ_max/Δt`;
  консервативно из-за корреляции проверок, объявлено.

## Отклонённые альтернативы

- **Гейт по `p_SL`** — запрещён §12: гейт только `EV_LCB`.
- **Безбарьерные формулы как операционные** — `REFERENCE_ONLY` (C3).
- **Подстановка `σ_P` вместо `σ` в bound касания** — запрещена §12 (C1).
- **Подбор `λ`, `q`, `α` post hoc** — запрещён; значения из политики R2.

## Риски

- `t½ > τ_cap` у всех инструментов: EV на горизонте `τ ≤ 60` считается в почти линейной области
  OU. Артефакты несут `regime = "tau_ll_t_half"` и `t_half/τ_max` (`PROJECT-DECISION:r3-slow-reversion`).
- HMM-15m на 8 неделях даёт мало переходов: Gate 2 может провалиться, тогда `τ_regime`/`τ_mtf`
  уходят в `REFERENCE_ONLY`, и `τ_max` определяется оставшимися компонентами.
- Данные могут быть sandbox-симуляцией (Gate 0b заблокирован): все выводы R3 — для этой выборки.
- Пропуски 3–31 % минут: первый проход по 1m с пропусками считается по фактическим барам,
  а не по идеальной сетке; направление смещения не оценено.
