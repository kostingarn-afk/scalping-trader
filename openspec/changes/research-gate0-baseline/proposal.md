# Proposal

## Why

`docs/buy_frame.md` (Research Spec v4.0) и `docs/holding_exiting.md` (Holding & Exit v1.0)
отменяют прежнюю операционную логику: цель `k×ATR`, простой EV-гейт по закрытым сделкам и
HMM на минутном ряду. Новый порядок (§16 `buy_frame.md`) начинается с проверки данных и единиц
измерения: без шага цены невозможно считать барьеры, издержки `C` и требуемую долю движения
`φ*`; без границ сессий — нельзя ни считать статистику, ни закрывать позицию до конца торгов.

Сейчас в проекте этого нет: шаг цены хранится только в БД и не попадает в выгрузку, сессионного
календаря нет, все пороги заданы в процентах и рублях, а не в тиках.

## What Changes

- **Единицы.** Каждый параметр исследования несёт поле `units`; без него значение отклоняется.
  Цены и барьеры — тики (целые), `θ,λ,β` — мин⁻¹, `C,S` — тики за круг.
- **Шаг цены.** В `.meta.json` выгрузки добавляется `min_price_increment` (Collector).
  Резолвер предпочитает метаданные; выведенный из сетки цен шаг помечается `UNVERIFIED`.
- **Сессии.** Конфигурируемое расписание (основная сессия MOEX, `buffer` до закрытия);
  бары вне сессий и ночные разрывы исключаются из статистики; `τ_session` считается из него.
- **Gate D.** Отчёт целостности: пропуски внутри сессий, нулевые объёмы, дубли и монотонность
  меток времени, аукционные принты, бары вне сессий, отсутствие overnight-доходностей в выборке,
  согласованность сетки цен с тиком, аномалии `|ΔP|` (включая корпоративные действия),
  распределение `|ΔP|` в тиках. Критичный провал останавливает исследование.
- **Дисперсии.** Range-based оценки (Parkinson, Garman–Klass, Rogers–Satchell), диагностика
  шума, `VR(τ)`, `σ_τ = σ_1·√(τ·VR(τ))`, десезонализация по минуте сессии.
- **Издержки.** `cost_estimate` — круг в тиках (ставка, минкомиссия, спред как оценка со
  статусом `UNVERIFIED`), стресс ×1.5; вход в `φ*(τ)` считается позже, в Gate 0a.
- **Метка.** Вариант метки (fixed-horizon либо triple-barrier) и `h_max` для purging в CPCV.
- **Trial registry.** Структура записи опытов и id в артефактах отбора — без него DSR
  невычислим.
- **CLI исследования.** `analyzer-research` (модуль `analyzer.research.cli`): `integrity`,
  `report`; отчёты пишутся в каталог, указанный `--out`.

Не входит: фаза A и Gate 0a (этап R1 плана), идентификация θ (R2), EV(τ)/τ* (R3), Gate 0b (R4),
runtime (R5). Причина разделения: по §16 спеки `φ*` считается после заморозки политики, а
`VR`/`σ_τ` — раньше; отклонение объявлено в `to_do.md` §4.

## Capabilities

### New Capabilities

- `research-validation`: единицы измерения, шаг цены, Gate D, сессии, дисперсии/`VR`,
  оценка издержек, метка, trial registry.

### Modified Capabilities

Нет.

## Impact

- Collector: `HistoryCsvWriter` — поле `min_price_increment` в `.meta.json`.
- Analyzer: новый пакет `analyzer/src/analyzer/research/` (`units`, `ticks`, `sessions`,
  `integrity`, `variance`, `costs`, `labels`, `registry`, `cli`); новый entry-point
  `analyzer-research`. В `backtest/loader.py` — чтение `min_price_increment` из meta.
- Тесты: `analyzer/tests/test_research_*.py`.
- БД, Kafka, Trader, `proto/` — не затрагиваются.
