# Spec Delta

## MODIFIED Requirements

### Requirement: Подписка на gRPC-стримы рыночных данных

Collector SHALL подписываться на `MarketDataStreamService` (bi-directional stream) для каждого инструмента из конфигурации с четырьмя типами подписок: Candles (1 мин, waiting_close=false), OrderBook (depth=10), Trades, Info.

Состав списка инструментов — параметр сессии, а не часть требования: он задаётся конфигурацией
(`collector.instruments`) и пересматривается по её итогам. Метод отбора — ATR(1h) ≥ 0.4 % и
оборот ≥ 100 млн ₽/день.

#### Scenario: Старт подписки на список инструментов
- **WHEN** Collector стартует с конфигурацией из N инструментов
- **THEN** открывается одно стрим-соединение и выставляются 4 × N подписок (N инструментов × 4 типа)

#### Scenario: Состав списка задаётся конфигурацией сессии
- **WHEN** список инструментов в конфигурации изменён между сессиями
- **THEN** Collector выставляет подписки по новому списку без изменений в коде; число подписок пересчитывается как 4 × N

#### Scenario: Превышение лимита подписок
- **WHEN** число запрошенных подписок превышает 300 (лимит соединения)
- **THEN** Collector открывает дополнительное стрим-соединение и распределяет подписки

#### Scenario: Резолв идентификаторов инструментов
- **WHEN** в конфигурации указан тикер без класса (`TICKER`) или с классом (`TICKER@CLASS`)
- **THEN** Collector разрешает тикер в FIGI через `InstrumentsService`: акции — класс `TQBR`, фьючерсы — класс `SPBFUT`; регистр тикера сохраняется
