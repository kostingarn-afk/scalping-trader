# Spec Delta

## ADDED Requirements

### Requirement: Оценка кластеризации сделок

Analyzer SHALL оценивать branching ratio потока сделок (`n = α/β` экспоненциального Hawkes) по
временам последних сделок инструмента и сохранять его в индикаторах анализа.

Оценка MUST возвращаться пустой, если сделок недостаточно для устойчивой оценки. Пересчёт MUST
происходить не на каждой сделке, а с заданной периодичностью; окно и периодичность MUST
задаваться конфигурацией.

#### Scenario: Пуассоновский поток

- **WHEN** сделки приходят равномерно (пуассоновский поток) и их достаточно для оценки
- **THEN** branching ratio близок к нулю

#### Scenario: Кластеризованный поток

- **WHEN** сделки идут всплесками с известным branching ratio
- **THEN** оценка близка к истинному значению в допуске, а не к нулю

#### Scenario: Мало сделок

- **WHEN** в окне меньше минимального числа сделок
- **THEN** индикатор `hawkes` пуст, и модель, требующая его, не входит в сделку

#### Scenario: Значение в записи анализа

- **WHEN** оценка рассчитана к моменту завершённой свечи
- **THEN** она сохраняется в `analysis_results.indicators` вместе с остальными индикаторами
