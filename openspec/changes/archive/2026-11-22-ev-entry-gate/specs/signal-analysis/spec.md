# Spec Delta

## ADDED Requirements

### Requirement: Вход только при положительной ожидаемой доходности

Analyzer и бэктест SHALL оценивать ожидаемую доходность сделки по фактическим исходам закрытых
сделок: `EV = p·avgWin − (1−p)·avgLoss`, где `p` — доля прибыльных сделок, `avgWin`/`avgLoss` —
средние модули прибыли и убытка после комиссии и издержек исполнения.

Сигнал MUST NOT приводить к входу при `EV ≤ 0`. Оценка MUST строиться на последних закрытых
сделках ограниченного окна, чтобы отражать текущий режим.

#### Scenario: Отрицательная ожидаемая доходность

- **WHEN** по последним сделкам `EV ≤ 0`
- **THEN** новые входы отклоняются, а в отчёте бэктеста растёт счётчик отсечённых гейтом сигналов

#### Scenario: Положительная ожидаемая доходность

- **WHEN** `EV > 0` и сигнал проходит остальные фильтры
- **THEN** вход разрешён

#### Scenario: Выборки недостаточно

- **WHEN** закрытых сделок меньше порога выборки
- **THEN** гейт не действует, и поведение остаётся прежним

#### Scenario: Односторонняя выборка

- **WHEN** в окне нет проигрышей или нет прибылей
- **THEN** оценка считается отсутствующей, и гейт не действует
