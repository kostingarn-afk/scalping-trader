# Proposal

## Why

Бэктест считает только комиссию брокера: вход исполняется по открытию следующего бара, выход —
по цене SL/TP без проскальзывания (`engine.py:207`, `_close_trade`). На минутном фрейме
(торговый ТФ — `1min`) полуспред и импакт сопоставимы с комиссией 0.05 %/сторона, поэтому
`gate` в отчёте завышен, и сравнение моделей идёт на оптимистичной модели издержек.

Шаг 1.6 плана (`to_do.md` §4.1) вводит модель исполнения Almgren–Chriss: цена входа хуже для
покупателя, цена выхода хуже для продавца, величина зависит от участия в объёме бара.

## What Changes

- **Модель издержек исполнения** — `backtest/execution.py`: `ExecutionModel` со спредом (б.п.
  цены) и временным/постоянным импактом Almgren–Chriss (б.п. при 100 % участии). Итоговая
  поправка: `spread + participation·(impact + 0.5·permanent)`, где
  `participation = units / (объём бара × размер лота)` с потолком 100 %.
- **Прогон** — поправка применяется к цене входа (покупка дороже, продажа дешевле) и к цене
  выхода (закрытие длинной — продажа, короткой — покупка). `exit_price` в сделке — фактическая
  цена исполнения.
- **Параметры** — `--spread-bps`, `--impact-bps`, `--permanent-bps`; дефолты 0 дают прежнее
  поведение без изменения результатов.
- **Отчёт** — при включённых издержках строка параметров называет спред и импакт, чтобы прогоны
  с разной моделью исполнения не выглядели одинаково.

Не входит: котирование LIMIT по Avellaneda–Stoikov (3.6), модель очереди, внутрибарная
траектория цены, калибровка коэффициентов по реальным исполнениям.

## Capabilities

### New Capabilities

- `backtest-execution`: модель издержек исполнения в бэктесте (спред, импакт, участие) и её
  отражение в отчёте.

### Modified Capabilities

Нет.

## Impact

- Код: новый `analyzer/src/analyzer/backtest/execution.py`; правки `models.py` (`RunConfig`),
  `engine.py` (вход и выход), `cli.py` (флаги), `report.py` (строка параметров).
- Тесты: `analyzer/tests/test_execution.py`, дополнение `test_backtest_engine.py`.
- Зависимости: без новых. БД, Kafka, `proto/` — не затрагиваются.
- Документация: `analyzer/README.md` §11 — модель исполнения и флаги.
