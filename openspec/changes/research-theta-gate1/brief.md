# Brief — research-theta-gate1

Этап **R2** плана `to_do.md` (§5, шаги R2.1–R2.4). Контекст: R0 и R1 закрыты и заархивированы;
Gate 0a пройден 19/20, окупаемость наступает при τ = 5–30.

## Шаги

1. **R2.1.** `research/theta.py`: ACF лог-цены на Δ ∈ {1,2,3,5,10,15,30} внутри окон,
   `θ̂_obs(Δ)`, регрессия на `1/Δ`, CI блочным bootstrap по сессиям, fallback на плато.
2. **R2.2.** Gate 1: CI интерсепта не содержит 0; CI `t_{1/2}` уже двукратного.
3. **R2.3.** `σ`, `σ_P`, `μ`, attenuation, `ρ_model` (диагностика).
4. **R2.4.** `ou_fit` с θ, σ, σ_P, μ, CI и id записи registry.

## Принятые решения

- **Пары только с точным шагом.** `ρ̂(Δ)` считается по парам, где метки времени отличаются ровно
  на Δ·60 с и обе точки внутри одного окна: иначе пропуски минут превращаются в «доходность за
  Δ», и θ̂ завышается.
- **Среднее по окну, а не по всей выборке.** Ковариация центрируется средним внутри окна:
  иначе ночной разрыв и разный уровень цены между днями дают ложную положительную корреляцию.
- **CI — bootstrap по сессиям.** Соседние бары зависимы; блочный bootstrap сохраняет
  внутрисессионную структуру, чего не даёт iid-bootstrap (запрещён §15 спеки).
- **Fallback по плато.** Если наклон регрессии неотличим от нуля (CI содержит 0) и `θ̂(Δ)`
  стабильна, берётся плато signature plot; метод помечается `PLATEAU` в `flags`.
- **Gate 1 трактуется по инструменту**, как Gate 0a: провал инструмента исключает его из
  кандидатов, исследование останавливается только если OU неприменим на всей выборке
  (`DEVIATION:gate0a-per-instrument` расширяется на Gate 1).

## Отклонённые альтернативы

- **θ̂ из AR(1) по минутным доходностям** — AR(1) доходностей и OU цены дают разные θ; спека
  требует инвариантности по Δ, поэтому основной метод — ACF уровня цены.
- **iid-bootstrap** — разрушает зависимость и занижает CI.
- **Склейка рядов через ночь** — даёт ложную корреляцию уровней (запрещено §11 спеки).

## Риски

- Пропуски 3–31 % минут (Gate D) уменьшают число пар на малых Δ; при нехватке пар строка
  помечается `NO_DATA`, а не подменяется соседним баром.
- Шаг цены `UNVERIFIED` не влияет на θ (она в мин⁻¹), но влияет на σ_P в тиках — пометка идёт в
  артефакт.
- Данные могут быть sandbox-симуляцией (§6.3 `to_do.md`): вывод Gate 1 валиден только для этой
  выборки и будет перепроверен после подтверждения происхождения ряда.
