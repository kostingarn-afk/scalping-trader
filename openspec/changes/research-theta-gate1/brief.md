# Brief — research-theta-gate1

Этап **R2** плана `to_do.md` (§5, шаги R2.1–R2.4). Контекст: R0 и R1 закрыты и заархивированы;
Gate 0a пройден 19/20, окупаемость наступает при τ = 5–30.

## Шаги

1. **R2.1.** `research/theta.py`: `ρ̂(Δ)` по лог-цене внутри окна (пары только при точном шаге),
   `θ̂_obs(Δ)`, регрессия на `1/Δ`, CI блочным bootstrap по сессиям, fallback на плато.
2. **R2.1a.** Дисперсионная оценка `Var(x_{t+Δ} − x_t) = (σ²/θ)(1 − e^{−θΔ}) + 2ω²`
   профильным МНК (модель линейна по `A` и `2ω²`, поиск только по θ).
3. **R2.1b.** Нулевая полоса: та же процедура на симулированном случайном блуждании с теми же
   длинами окон; зависит только от геометрии (оценки масштабно-инвариантны).
4. **R2.2.** Gate 1: CI интерсепта не содержит 0, CI `t_{1/2}` уже двукратного, обе оценки выше
   своих полос.
5. **R2.3.** `σ`, `σ_P`, `μ`, attenuation, `ρ_model` (диагностика), `θ_used`.
6. **R2.4.** `ou_fit` с θ, σ, σ_P, μ, CI и id записи registry.

## Принятые решения

- **Оценка по спеке остаётся, но её вердикт не принимается «как есть».** Проверка на синтетике:
  ACF внутри окна даёт на чистом случайном блуждании `θ̂ = 0.0095 ± 0.0022` с узким CI и
  Gate 1 = PASS. Причина — удаление среднего по окну из сильно коррелированного ряда:
  `ρ̂(30) = 0.126` против теоретических `0.215` на 400 независимых окнах. Смещение растёт с Δ,
  поэтому `θ̂(Δ)` растёт с Δ и член регрессии на `1/Δ` перестаёт быть шумовой поправкой.
  Решение владельца (2026-11-22): обе оценки + нулевая полоса, спека не отменяется.
- **Нулевая полоса, а не только bootstrap-CI.** Bootstrap меряет разброс между сессиями и
  смещение метода не видит. Полоса считается по геометрии окон (масштабная инвариантность),
  поэтому не требует ни цены, ни волатильности.
- **Дисперсионная оценка не смещена удалением среднего:** приращения инвариантны уровню окна.
  На синтетике θ = 0.05 восстанавливается в пределах 20 %.
- **Расхождение оценок — флаг, а не блокер.** ACF смещена вверх, дисперсионная вниз
  (на данных отношение ACF/дисп. достигает 2.9); блокировать по разнице двух смещённых оценок
  значило бы задать порог «на глаз». Блокирует только полоса.
- **`θ_used` для OU — дисперсионная оценка**, если построена: она менее смещена.
- **Эскалация Δ до 60 при θ ≤ 0.02** (решение владельца): флаг `--escalate`, значения
  записываются в registry и в флаги артефакта. Расширение — не ослабление гейта.
- **`t½ > τ_cap` — диагностический флаг `SCOPE`**, а не причина отказа: вопрос о пригодности
  горизонта решается в R3, но факт обязан быть виден в отчёте.

## Отклонённые альтернативы

- **θ̂ из AR(1) по минутным доходностям** — AR(1) доходностей и OU цены дают разные θ; спека
  требует инвариантности по Δ, поэтому основной метод — ACF уровня.
- **iid-bootstrap** — разрушает зависимость и занижает CI.
- **Склейка рядов через ночь** — даёт ложную корреляцию уровней (§11 спеки).
- **`curve_fit` для дисперсионной модели** — отвергнут: с нижней границей θ он возвращал
  ложные 0.038 на случайном блуждании. Профильный МНК даёт точный МНК по θ и θ → 0 на блуждании.
- **Блокировка по расхождению оценок** — порог пришлось бы брать «на глаз»; вынесено в флаг.

## Результаты реального прогона (2026-11-22, 20 инструментов)

Опыт `cd370497c53d` (`reports/research/theta.json`, каталог в `.gitignore`):
тариф не используется, сетка Δ = {1,2,3,5,10,15,30}, bootstrap 200, нулевая полоса 100,
`τ_cap = 60`.

| Показатель | Значение |
|---|---|
| Gate 1 PASS | 14 из 20 |
| Провал | CHMF, LKOH, NLMK, NVTK, SNGS, TATN — ACF-оценка ниже полосы блуждания |
| `θ` (ACF) | 0.0064–0.0097 мин⁻¹ |
| `θ` (дисперсионная) | 0.0022–0.0137 мин⁻¹ |
| `t_{1/2}` (ACF) | 71–109 мин |
| `t½ > τ_cap = 60` | **у всех 20** |
| Расхождение оценок > 1.5× | 8 инструментов (до 2.87× на TATN) |

Следствия (в `to_do.md` §1.1 и §6):

1. **Возврат медленнее горизонта скальпинга.** `t½` 71–109 мин против `τ_cap = 60`: даже там,
   где Gate 1 пройден, модель описывает процесс, который за горизонт удержания не разворачивается.
2. **Эскалация до Δ = 60 не меняет вывод:** на AFLT `θ` = 0.00821 (Δ ≤ 30) против 0.00849
   (Δ ≤ 60), полоса поднялась с 0.00743 до 0.00781 — соотношение то же.
3. **Наблюдаемая «быстрая» возвратность — микроструктурный шум.** `VR(30)` из R0 равен
   0.34–0.70, что соответствует θ ≈ 0.08, но дисперсионная оценка, явно моделирующая шумовой
   член, даёт θ ≈ 0.0035. Значит основной вклад в `VR < 1` даёт отскок от спреда (издержка),
   а не возврат эффективной цены (edge).
4. **Абсолютная величина смещения ACF зависит от длины окна** (полоса считается по той же
   геометрии), поэтому сравнивать `θ` между инструментами с разной длиной окон нельзя напрямую.

## Риски

- Пропуски 3–31 % минут уменьшают число пар на малых Δ; `NO_DATA` вместо подстановки соседа.
- Шаг цены `UNVERIFIED` не влияет на θ (мин⁻¹), но влияет на σ_P в тиках — пометка в артефакте.
- Данные могут быть sandbox-симуляцией (§6.3 `to_do.md`): вывод Gate 1 валиден только для этой
  выборки и перепроверяется после подтверждения происхождения ряда (блокирует Gate 0b).
