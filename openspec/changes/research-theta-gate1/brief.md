# Brief — research-theta-gate1

Этап **R2** плана `to_do.md` (§5, шаги R2.1–R2.5). Контекст: R0 и R1 закрыты и заархивированы;
Gate 0a пройден 19/20, окупаемость наступает при τ = 5–30.

## Шаги

1. **R2.1.** `research/theta.py`: `ρ̂(Δ)` по лог-цене внутри окна (пары только при точном шаге),
   `θ̂_obs(Δ)`, регрессия на `1/Δ`, CI блочным bootstrap по сессиям, fallback на плато.
2. **R2.1a.** Дисперсионная оценка `Var(x_{t+Δ} − x_t) = (σ²/θ)(1 − e^{−θΔ}) + 2ω²`
   профильным МНК (модель линейна по `A` и `2ω²`, поиск только по θ).
3. **R2.1b.** Нулевая полоса: та же процедура на симулированном случайном блуждании с теми же
   длинами окон; зависит только от геометрии (оценки масштабно-инвариантны).
4. **R2.2.** Gate 1: CI оценки не содержит 0, CI `t_{1/2}` не шире двукратного, обе оценки выше
   своих полос, дисперсионная θ идентифицирована.
5. **R2.3.** `σ` (из дисперсионной модели), `σ_P`, `μ`, attenuation, `ρ_model`, `θ_used`.
6. **R2.4.** `ou_fit` с θ, σ, σ_P, μ, CI и id записи registry.
7. **R2.5.** Эскалация сетки Δ до 60 (`--escalate`) с записью в registry и флагом
   `SUGGEST_ESCALATION` при `θ_used ≤ 0.02`.

## Принятые решения

- **Оценка по спеке остаётся, но её вердикт не принимается «как есть».** Проверка на синтетике:
  ACF внутри окна даёт на чистом случайном блуждании `θ̂ = 0.0095 ± 0.0022` с узким CI и
  Gate 1 = PASS. Причина — удаление среднего по окну из сильно коррелированного ряда:
  `ρ̂(30) = 0.126` против теоретических `0.215` на 400 независимых окнах. Смещение растёт с Δ,
  поэтому `θ̂(Δ)` растёт с Δ и член регрессии на `1/Δ` перестаёт быть шумовой поправкой.
  Решение владельца (2026-11-22): обе оценки + нулевая полоса, спека не отменяется.
- **Нулевая полоса, а не только bootstrap-CI.** Bootstrap меряет разброс между сессиями и
  смещение метода не видит. Полоса считается по геометрии окон, поэтому не требует ни цены,
  ни волатильности. Отсутствующая граница пишется как `null`, а не ноль: «полосы нет» обязано
  отличаться от «полоса нулевая».
- **Окно оценки 4–8 недель по §6.3 реализовано параметром `--weeks` (по умолчанию 8).**
  `--weeks 0` — вся история как диагностический режим; в артефакте окно помечается
  `mode: "full-history"`, чтобы его нельзя было прочитать как «4–8 недель».
- **σ для OU — из дисперсионной модели (`σ² = A·θ`)**, а не СКО доходностей: СКО включает
  микроструктурный шум и проходы через пропуски минут (на данных расхождение до 1.7×).
  Наивная оценка публикуется рядом (`sigma_naive`) и при расхождении > 1.25× помечается флагом.
- **`2ω²` называется своим именем.** Свободный член модели — это `2ω²`; поле `two_omega_sq`,
  чтобы при переносе в R3 значение не было использовано вдвое больше.
- **Вырожденность дисперсионной оценки — явный флаг.** На блуждании профиль МНК вырожден
  (идентифицируется только `A·θ`), минимум лежит на границе сетки: `identified = False`,
  Gate 1 не проходит. Значение на границе — предел перебора, а не оценка.
- **Расхождение оценок — флаг, а не блокер.** ACF смещена вверх, дисперсионная вниз
  (на данных отношение достигает 2.9); блокировать по разнице двух смещённых оценок значило бы
  задать порог «на глаз». Блокирует полоса.
- **`θ_used` для OU — дисперсионная оценка**, если она идентифицирована.
- **Артефакты разделены по смыслу:** `theta-invariance.json`, `signature-plot.json`,
  `null-band.json`, `ou-fit.json` — каждый в конверте с единицами, `n`, методом и флагами;
  `theta.md` — человекочитаемая сводка.

## Отклонённые альтернативы

- **θ̂ из AR(1) по минутным доходностям** — AR(1) доходностей и OU цены дают разные θ; спека
  требует инвариантности по Δ, поэтому основной метод — ACF уровня.
- **iid-bootstrap** — разрушает зависимость и занижает CI.
- **Склейка рядов через ночь** — даёт ложную корреляцию уровней (§11 спеки).
- **`curve_fit` для дисперсионной модели** — отвергнут: с нижней границей θ он возвращал
  ложные 0.038 на случайном блуждании. Профильный МНК даёт МНК по θ при фиксированных
  линейных коэффициентах и на блуждании уходит к нижней границе сетки.
- **Блокировка по расхождению оценок** — порог пришлось бы брать «на глаз»; вынесено в флаг.

## Результаты реального прогона (2026-11-22, 20 инструментов, окно 8 недель)

Опыт `99102a1b84bb` (`reports/research/`, каталог в `.gitignore`), сетка Δ = {1,2,3,5,10,15,30},
bootstrap 200, нулевая полоса 100, `τ_cap = 60`.

| Показатель | Значение |
|---|---|
| Gate 1 PASS | **4 из 20** (MTSS, PLZL, T, VTBR) |
| `θ` (ACF) | 0.0053–0.0111 мин⁻¹ |
| `θ` (дисперсионная) | 0.0013–0.0134 мин⁻¹; у MOEX, ROSN, SNGS минимум на границе сетки (`identified = False`) |
| `t_{1/2}` | 62.6–131.8 мин |
| `t½ > τ_cap = 60` | **у всех 20** |
| σ модели против наивной | 0.60–0.67× (MTSS, PLZL), совпадает у T |

Эскалация (опыт `29c77efd4c09`, `--escalate`, те же окна): **5 из 20** — добавляется SBER;
`θ` возрастает на 0.7–9.6 %, полоса на 3.5–8.5 % (AFLT: `θ` 0.00711 → 0.00732,
полоса 0.00890 → 0.00924).

Следствия (в `to_do.md` §1.1 и §6.3):

1. **Возврат медленнее горизонта скальпинга у всех 20:** `t½` ≥ 62.6 мин при `τ_cap = 60`.
2. **Окно оценки решает вердикт:** на всей истории (10 месяцев) проходили 14 из 20, на 8 неделях
   — 4. Полоса на коротком окне шире, потому что меньше независимых окон. Спека требует 4–8
   недель, поэтому отчётным считается прогон на 8 неделях; длинная история — только диагностика.
3. **Эскалация до Δ = 60 не меняет вывод:** +1 инструмент, порядок θ и `t½` те же.
4. **Наблюдаемая «быстрая» возвратность — микроструктурный шум.** `VR(30)` из R0 (0.34–0.70)
   соответствовал бы θ ≈ 0.03–0.08, но дисперсионная оценка, явно моделирующая шумовой член,
   даёт θ ≤ 0.013. Основной вклад в `VR < 1` — отскок от спреда (издержка), а не возврат
   эффективной цены (edge).

## Риски

- Пропуски 3–31 % минут уменьшают число пар на малых Δ; `NO_DATA` вместо подстановки соседа.
- Шаг цены `UNVERIFIED` не влияет на θ (мин⁻¹), но влияет на σ_P в тиках — пометка в артефакте.
- Данные могут быть sandbox-симуляцией (§6.3 `to_do.md`): вывод Gate 1 валиден только для этой
  выборки и перепроверяется после подтверждения происхождения ряда (блокирует Gate 0b).
- Наивная σ завышает σ_P на десятки процентов; в артефакте обе величины, выбор — за `sigma`.
- Нулевая полоса — случайная величина на 100 репликах; запас над ней стоит читать вместе
  с флагом `variance_margin`, а не как точную границу.
