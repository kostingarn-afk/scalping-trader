# Proposal

## Why

Gate 0a пройден (19 из 20), но он отвечает только на вопрос «хватает ли движения». Следующий шаг
по §16 `buy_frame.md` — идентификация параметров OU: `θ` (скорость возврата), `σ`, `σ_P`,
`ρ_model`, и **Gate 1**: можно ли вообще измерять θ на этих данных. Если CI интерсепта содержит
0, модель mean reversion неприменима, и все дальнейшие EV(τ) считать запрещено (§6.3).

Наблюдение Gate 0a усиливает требование: окупаемость наступает при τ = 5–30 минут, значит θ
нужна на горизонте, сопоставимом с удержанием. Набор Δ расширен до 30 (объявленное отклонение
`DEVIATION:delta-grid-30` в `to_do.md` §4).

## What Changes

- **θ̂(Δ)** — ACF лог-цены на Δ ∈ {1, 2, 3, 5, 10, 15, 30} мин внутри торговых окон;
  `θ̂_obs(Δ) = −ln ρ̂(Δ) / Δ`. Пары считаются только при точном совпадении меток времени и
  внутри одного окна: пропуски не «склеиваются» в ложную доходность.
- **Инвариантность** — регрессия `θ̂_obs(Δ)` на `1/Δ`: интерсепт = шум-скорректированная θ,
  slope = логарифм шумового отношения. CI — блочный bootstrap по сессиям.
- **Fallback** — если наклон неотличим от нуля, берётся плато signature plot; выбор метода
  пишется в `flags`.
- **Gate 1** — CI интерсепта не содержит 0; CI `t_{1/2}` уже двукратного.
- **OU-параметры** — `σ`, `σ_P = σ/√(2θ)`, `μ`, attenuation `σ_P²/(σ_P²+ω²)`, `ρ_model` как
  диагностика (в Gate 0 не подставляется).
- **CLI** — подкоманда `theta`; артефакты `theta_invariance_regression`, `signature_plot`,
  `ou_fit`.

Не входит: EV(τ), τ*, правило удержания (R3), Gate 0b (R4), runtime (R5).
