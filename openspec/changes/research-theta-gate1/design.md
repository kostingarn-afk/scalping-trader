# Design — research-theta-gate1

## 1. Оценка θ по инвариантности

Модель: `P* = P + η`, `Var(η) = ω²`, `σ_P² = σ²/(2θ)`. Для OU с шумом
`θ̂_obs(Δ) = θ + ln(1 + ω²/σ_P²)/Δ` (§6.3 `buy_frame.md`).

Реализация:

1. Лог-цена `x = ln(close)`, сгруппированная по торговым окнам (`SessionSchedule.window_at` +
   дата). Бары вне окон отбрасываются: ночной разрыв в выборку не попадает.
2. Для каждого Δ: пары `(x_t, x_{t+Δ})`, где метки отличаются ровно на `Δ·60 с`. Пары
   центрируются средним **внутри окна**; `ρ̂(Δ) = Σ(x_t−μ)(x_{t+Δ}−μ) / Σ(x_t−μ)²`.
3. `θ̂_obs(Δ) = −ln ρ̂(Δ) / Δ`; корректно только при `0 < ρ̂ < 1` — иначе `NO_DATA`
   (ρ̂ ≥ 1 — шум/дрейф, ρ̂ ≤ 0 — нет памяти).
4. OLS `θ̂_obs(Δ)` на `1/Δ`: интерсепт = `θ`, наклон = `ln(1 + ω²/σ_P²)`,
   шумовое отношение `κ = e^{slope} − 1`.
5. CI интерсепта — percentile bootstrap по сессиям (ресамплинг списка окон, пересчёт агрегатов
   из заранее посчитанных по-сессионных сумм). Иначе 200 ресамплов по 280 тыс. баров — минуты
   счёта.

Почему не OLS по времени: θ̂(Δ) имеет разную дисперсию по Δ (малые Δ — больше шума), но
взвешивание подбирало бы веса по данным. Наблюдаемое расхождение попадает в CI.
`DEVIATION:ols-equal-weights`.

## 2. Fallback: плато signature plot

Если наклон неотличим от нуля (CI наклона содержит 0) и `θ̂(Δ)` не меняется больше чем на 20 %
между Δ = 15 и 30, используется плато: `θ = median(θ̂(Δ) для Δ ≥ 10)`, метод `PLATEAU`.
Причина: при отсутствии шума зависимость вырождается в горизонтальную линию, и интерсепт
регрессии численно нестабилен.

## 3. Gate 1

Проходит, если:

- CI интерсепта не содержит 0 и нижняя граница > 0 (θ положительна);
- CI `t_{1/2} = ln2/θ` уже двукратного: `upper/lower ≤ 2`.

Иначе инструмент получает `THETA_UNDEFINED`; OU для него не используется (`buy_frame.md` §13).
Вердикт по инструменту; прогон останавливается, если Gate 1 провален на всех инструментах.

## 4. OU-параметры

- `σ²` — дисперсия 1-минутных десезонализованных доходностей внутри окон (квадратическая
  вариация на единицу времени).
- `σ_P² = σ²/(2θ)`; `μ` — среднее лог-цены по окнам (якорь для `A_t`).
- attenuation `σ_P²/(σ_P² + ω²)` с `ω² = κ·σ_P²` → `1/(1+κ)`; помечается `CONSERVATIVE`,
  если `κ` получен из регрессии с CI, содержащим 0.
- `ρ_model(τ) = −√((1 − e^{−θτ})/2)` — диагностика для сравнения с `φ̂` в Gate 0b (в Gate 0
  не подставляется).

## 5. Артефакты и CLI

`theta_invariance_regression`: точки `(Δ, ρ̂, θ̂, pairs, status)`, интерсепт, наклон, CI,
метод, `flags`. `signature_plot` — те же точки в markdown. `ou_fit` — θ, σ, σ_P, μ,
attenuation, `ρ_model(τ)` для τ сетки, CI, id записи registry.

CLI: `analyzer-research theta --data-dir … --out … [--deltas 1,2,3,5,10,15,30]
[--bootstrap 200] [--policy …]`. Код возврата: 0 — Gate 1 пройден хотя бы одним инструментом,
1 — провал на всех, 2 — ошибка ввода.

## 6. Границы

EV(τ), τ*, правило удержания (R3) и Gate 0b (R4) в это изменение не входят. `theta.py`
возвращает `OuFit`, который R3 использует без переделки: θ, σ_P, CI и якорь `μ`.
