## 1. Задача

Определить, есть ли у торговой системы положительное математическое ожидание **после издержек**.
Реальные деньги не вносятся до подтверждения.

**Критерий приёмки:** `gate` (`gross / комиссия`) ≥ 1, `t ≥ 2` на out-of-sample, ≥ 50 сделок,
прибыль переживает удаление 3 лучших периодов (считается автоматически, колонка
`Net без 3 лучших %`), устойчиво между инструментами и периодами.

| Параметр | Значение |
|---|---|
| Депозит (расчётный) | 200 000 ₽ |
| Риск на сделку / дневной лимит | 1 % / 3 % (`risk_config`) |
| Инструменты | параметр сессии; отбор: ATR(1h) ≥ 0.4 %, оборот ≥ 100 млн ₽/день |
| Тариф, на котором торговля возможна | «Трейдер» 0.05 % за сторону |
| Глубина истории | ≤ 1 год (глубже не выгружается) |
| Режим | sandbox |

---

## 2. Правила реализации (установлены замерами)

| Правило | Основание |
|---|---|
| **5-дневный momentum при 10-дневном удержании не торгуется** | значимо убыточен: net −52 %, t −2.46; после удаления 3 лучших периодов −68 %, t −4.09 — убыток размазан по периодам, а не собран в трёх, поэтому это структура, а не везение |
| **Зеркальный разворот на тех же окнах не торгуется** | его прибыль (+47 %) держится на трёх моментах рынка: после обрезки +23 % при t 1.33, walk-forward OOS t 1.83 < 2 |
| Любой кандидат проходит проверку на концентрацию | если после удаления 3 лучших периодов знак меняется или t < 2 — преимущества нет |
| В панели издержки не ограничение (gate 20–27) | искать устойчивость сигнала, а не дешевизну |
| Запрет входов до 11:00 МСК | первый час основной сессии: −3.8 б.п. дрейфа, t −2.53 |
| Дневной стоп 3 % — правило портфеля | при 1 % риска на одну позицию не срабатывает (проверено) |
| Ротация бумаги: ≥ 15 % за окно **и** кандидат по фильтру | 15 % ≈ 1.8 сигмы шума; меньший порог срабатывает от случайности |
| История глубже 1 года не выгружается | требование владельца; глубина не создаёт преимущество |
| Состав списка — параметр сессии | отбор по ATR и обороту, а не по PnL бэктеста |

## 3. Состояние

**Закрыто и проверено** — повторно не открывать без новых данных:

- Mean reversion на одном имени: gross ≈ 0 на всех ТФ.
- Momentum на одном имени: 79 % net давали 3 сделки из 79.
- Панель: momentum (окна 5–63 дня), разворот, сигналы с поправкой на бету и риск — лучший OOS t 1.83.
- Пары и коинтеграция: Engle–Granger p ≥ 0.286 во всех 10 парах; Hurst в пределах шума.
- Внутридневная сезонность: ни один час не перекрывает круговую комиссию 10 б.п.

**Единственный устойчивый факт:** первое правило §2.

## 6. Команды

```bash
cd analyzer && export PYTHONPATH=src     # PowerShell: $env:PYTHONPATH = "src"

# Панель: в отчёте автоматически есть «Net без 3 лучших %»
UNIVERSE=$(cd ../data/history-1h && ls *_60min.csv | sed 's/_60min\.csv$//' | paste -sd,)
.venv/Scripts/python.exe -m analyzer.backtest.cli --data-dir ../data/history-1h \
  --tariffs trader --panel --panel-universe "$UNIVERSE" \
  --panel-grid "lookback_days=5,10,20;rebalance_days=5,10;legs=3,4" --panel-null-seeds 100

# Одиночная стратегия: окно входа и дневной стоп
.venv/Scripts/python.exe -m analyzer.backtest.cli --data-dir ../data/history-1h \
  --intervals 60 --tariffs trader --strategy momentum --z-entry 1.5 --no-tp \
  --max-bars 48 --trailing-atr 3.5 --entry-after-msk "11:00" --daily-stop 3

# Тесты
.venv/Scripts/python.exe -m pytest tests -q \
  --ignore=tests/test_handler.py --ignore=tests/test_signal_publisher.py
mvn -pl trader -am test        # в WSL: в Windows maven не установлен
```

## 7. Что не делать

| Антипаттерн | Почему |
|---|---|
| Менять бумагу по результату бэктеста | подгонка под шум: на новых данных убыточной окажется другая |
| Менять бумагу при убытке меньше 15 % | шум бумаги за 20 торговых дней ≈ 8.5 % |
| Оценивать результат без обрезки лучших периодов | 2–3 периода дают половину «прибыли» |
| Сравнивать дрейф часа с нулём, а не с издержками | круговая комиссия 10 б.п. больше любого часового дрейфа |
| Выгружать историю глубже 1 года | запрещено требованием |
| Вносить деньги до подтверждённого edge | проверка гипотезы стоит времени, а не денег |
